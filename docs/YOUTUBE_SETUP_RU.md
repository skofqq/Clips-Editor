# Подключение YouTube

Для загрузки видео приложению нужен собственный OAuth-клиент Google.
Это бесплатно, настраивается один раз и занимает минут 10.
Ключ остаётся у тебя: приложение не использует чужих серверов.

## 1. Проект и YouTube Data API

1. Открой <https://console.cloud.google.com/> и создай проект
   (например, `Twitch Shorts Studio`).
2. Перейди в **APIs & Services → Library**, найди **YouTube Data API v3**
   и нажми **Enable**.

## 2. Экран согласия (Google Auth Platform)

1. Открой **APIs & Services → OAuth consent screen**
   (раздел может называться **Google Auth Platform**) и нажми **Get started**.
2. Заполни название приложения и email поддержки. В пункте Audience выбери
   **External**, укажи контактный email и нажми **Create**.
3. В разделе **Audience → Test users** добавь свой Google-аккаунт,
   которому принадлежит канал.

## 3. Ключ клиента

1. Открой **Clients** (или **Credentials → Create credentials → OAuth client ID**).
2. В поле Application type выбери **Desktop app**, задай любое имя и нажми **Create**.
3. Нажми **Download JSON**. Скачается файл `client_secret_….json`.

## 4. В приложении

1. Открой **Settings → Integrations → YouTube Accounts…** и нажми
   **Load client_secret.json…**. Ключ сохранится в диспетчере учётных
   данных Windows, после этого файл можно удалить.
2. Нажми **Connect…**. Откроется браузер: выбери аккаунт и канал.
3. Google предупредит, что приложение не проверено. Это нормально, ведь
   приложение твоё: нажми **Continue / Продолжить** и разреши доступ.
4. Канал появится в списке. Теперь после экспорта можно нажать
   **Upload to YouTube…**.

Пароль от Google приложение не видит, вход идёт на странице Google.
Токены хранятся в диспетчере учётных данных Windows, а не в файлах проекта.

## Ограничения Google, которые важно знать

- **Видео остаются приватными.** YouTube оставляет ролики, загруженные
  через непроверенный API-проект, приватными, пока проект не пройдёт аудит
  YouTube API Services. Чтобы снять ограничение, подай заявку на аудит
  в форме YouTube API Services Audit and Quota Extension. Пока аудита нет,
  публикуй ролик вручную в YouTube Studio: загрузка, название, описание
  и теги уже будут готовы.
- **Режим Testing.** Пока приложение в режиме Testing, вход действует
  7 дней. После этого нажми **Reconnect**. Чтобы не повторять это каждую
  неделю, переведи приложение в **Audience → Publish app (In production)**.
  Предупреждение о непроверенном приложении при входе останется.
- **Квота.** По умолчанию Google даёт 10 000 единиц квоты в день,
  а одна загрузка стоит большую её часть (по документации 1600 единиц).
  Получается примерно 6 загрузок в сутки. Квота обновляется в полночь
  по тихоокеанскому времени.

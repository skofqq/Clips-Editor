# Подключение TikTok

Приложение публикует готовый Short в TikTok через официальный **Content Posting API**.
Для этого нужно своё приложение разработчика TikTok (бесплатно). Это делается один раз.

## 1. Аккаунт разработчика

1. Открой <https://developers.tiktok.com/> и войди своим аккаунтом TikTok.
2. **Manage apps → Connect an app**. Название, например, `Twitch Shorts Studio`,
   категория **Video/Entertainment**, платформа **Desktop**.

## 2. Продукты и разрешения

1. В приложении нажми **Add products** и добавь **Login Kit** и **Content Posting API**.
2. В **Content Posting API** включи **Direct Post** (публикация сразу в профиль).
3. В **Scopes** должны быть `user.info.basic`, `video.upload`, `video.publish`.
4. В **Login Kit → Redirect URI** (Desktop) добавь ровно:
   `http://localhost:8765/callback/`

## 3. Ключи

На странице приложения скопируй **Client key** и **Client secret** и вставь их
в поля ниже, в этой панели. Ключи хранятся в диспетчере учётных данных Windows.

## 4. Подключение

1. Нажми **Save and connect TikTok**. Откроется браузер: войди и разреши доступ.
2. Пока приложение в статусе **Sandbox**, добавь свой аккаунт TikTok в
   **Sandbox → Target users**, иначе вход не пройдёт.

## Ограничения TikTok

- **Аудит.** Пока TikTok не проверит приложение, публиковать можно только с
  видимостью **«Only me»** (видно только тебе), а аккаунт должен быть закрытым.
  Чтобы публиковать для всех, отправь приложение на проверку
  (**Submit for review**, нужно описание и видео работы приложения).
- **Без аудита удобнее «Send to TikTok drafts»**: ролик придёт во «Входящие»
  приложения TikTok на телефоне, там можно поставить звук, обложку и
  опубликовать как обычно, для всех.
- Лимит: около 15 публикаций в день на аккаунт через API.
- Обложка ролика берётся из кадра, выбранного на странице Data (Thumbnail).

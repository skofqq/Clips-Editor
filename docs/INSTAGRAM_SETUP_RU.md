# Подключение Instagram Reels

Приложение публикует готовый Short как Reels через официальный
**Instagram API with Instagram Login**. Это делается один раз.

## 1. Профессиональный аккаунт

Reels через API публикуются только с профессионального аккаунта.
В приложении Instagram: **Настройки → Тип аккаунта и инструменты →
Переключиться на профессиональный аккаунт** (Автор или Бизнес). Привязывать
страницу Facebook для этого способа не нужно.

## 2. Приложение Meta

1. Открой <https://developers.facebook.com/apps/> и нажми **Create app**.
2. Сценарий (use case): **Manage messaging & content on Instagram**.
   Тип **Business**.
3. В приложении открой **Instagram → API setup with Instagram login**.
4. В **Add account** добавь свой Instagram и подтверди вход.
   Пока приложение в режиме разработки, аккаунт должен быть в
   **App roles → Roles** как **Instagram Tester** (приглашение принимается в
   Instagram: Настройки → Приложения и сайты → Приглашения тестировщика).

## 3. Токен

1. В том же разделе нажми **Generate token** напротив своего аккаунта и
   разреши доступ, включая **instagram_business_content_publish**.
2. Скопируй токен и вставь его в поле ниже, в этой панели, затем нажми
   **Connect Instagram**.

Токен действует 60 дней. Приложение само продлевает его, если запускать его
хотя бы раз в 60 дней. Если срок всё же истёк, сгенерируй новый токен.
Токен хранится в диспетчере учётных данных Windows.

## Ограничения Instagram

- До 50 публикаций через API за сутки.
- Reels: от 3 секунд до 15 минут, 9:16, MP4 (H.264 или HEVC), до 300 МБ.
  Короткие ролики из приложения подходят.
- Обложка берётся из кадра, выбранного на странице Data (Thumbnail).
- Опция «Also show in the feed» показывает Reels ещё и в ленте профиля.

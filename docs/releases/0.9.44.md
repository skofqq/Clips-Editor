**Имя файла обложки из названия клипа**

- При сохранении обложки на ПК (Data → Thumbnail → «Save image…») имя файла по умолчанию теперь берётся из названия клипа до символа «|». Например, для «Охота | #sasavot on #Twitch» будет предложено «Охота.jpg». Символы, которые Windows не разрешает в именах файлов, убираются. Если названия нет, предлагается прежнее имя «<клип>_thumbnail.jpg».

**Обновление программы прямо из неё**

- Help → Check for Updates: программа сама находит новую версию на GitHub, показывает, что изменилось, скачивает небольшой пакет обновления и ставит его поверх. Модели, настройки и история остаются на месте, переустанавливать ничего не нужно.
- При запуске новая версия проверяется тихо (можно выключить: Help → Check for Updates at Start). Кнопка «Update to …» появляется в строке состояния.
- «Skip this version» — не напоминать про эту версию.

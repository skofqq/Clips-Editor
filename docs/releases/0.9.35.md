**Метаданные заполняются сами: участники по голосам и данные с прошлого клипа**

- Data → Metadata, строка «Voices»: после «Find speakers» (или кнопки «Find voices») у каждого голоса есть список людей из библиотеки. Назовите голос один раз — в следующих клипах программа узнает его сама и добавит человека в участники. Голос стримера ставится в поле Streamer, если оно пустое.
- Новый клип стримера сразу получает участников, игру, тип стрима, шаблон, доп. теги и хэштеги с его последнего клипа; описание и теги генерируются. Название клипа, дата и ссылка на стрим остаются пустыми. Кнопка «Undo» убирает скопированное, галочка «Fill a new clip from the streamer's last clip» выключает это.

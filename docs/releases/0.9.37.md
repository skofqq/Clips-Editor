**Правка слов в транскрипте без потери таймингов**

- В строку слова теперь можно вписать несколько слов («ещё один»): время этого слова делится между ними по числу букв, остальные слова фразы сохраняют точные тайминги. Подсветка по словам в субтитрах и цензура работают как раньше.
- Пустая строка слова удаляет это слово (кроме последнего слова фразы — его удаляют, очистив строку фразы).
- Правка строки фразы больше не сбрасывает тайминги всей фразы, если число слов поменялось. Совпавшие слова (без учёта регистра, ё/е и знаков препинания) сохраняют своё время, изменённый кусок получает время заменённых слов, вставленное слово занимает паузу рядом (если она есть) или делит время с соседним словом, удалённые слова просто пропадают.
- Если правку принять нельзя, рядом со строкой появляется подсказка с причиной вместо молчаливого отката.
- Подсветка текущего шага (Edit / Data / Render / Publish) больше не съезжает с кнопки, когда у шагов появляется галочка ✓.

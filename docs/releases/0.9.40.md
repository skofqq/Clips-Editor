**Скачивание записи стрима (VOD) по ссылке**

- File → «Download Stream Recording (VOD)…» (Ctrl+Shift+D): вставьте ссылку twitch.tv/videos/…, укажите отрезок «from 1:20:00 to 2:00:00» (пустое «to» = до конца, кнопка «Whole stream» = вся запись) и качество (1080p60 source, 720p, …, Audio only). Окно сразу показывает канал, название, длину записи и примерный размер файла.
- Скачивается только выбранный кусок: Twitch хранит запись кусочками по ~10 с, программа берёт нужные (по 6 сразу) и склеивает их без перекодирования в MP4. Края округляются до этих кусочков, поэтому файл может начаться на несколько секунд раньше и закончиться чуть позже.
- Время можно писать как 1:20:00, 80:00, 4800, 1h20m или 1ч20м. Если в ссылке есть ?t=1h20m, начало подставится само.
- Окно не блокирует редактор: пока качается, можно работать дальше. Видна скорость и сколько осталось. Cancel останавливает сразу, скачанные кусочки остаются, и следующий Download продолжит с них. При выходе из программы во время загрузки она спросит.
- Когда файл готов, он появляется в Media и открывается. Чат этого отрезка скачивается сам и уже лежит во вкладке Highlights (время чата выровнено по началу файла). Страница Data заполняется стримером, игрой и датой с Twitch.
- Ссылку на запись можно и перетащить из браузера в окно, и вставить в File → Import from Twitch: откроется окно записи.
- Если Twitch заглушил кусок из-за музыки, это сказано в статусе: звука там нет. Записи только для подписчиков скачать нельзя.

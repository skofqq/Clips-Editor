**Плейлист стримера на YouTube**

- Загруженный клип сам попадает в плейлист стримера (стример берётся из чипа Streamer на странице Data). Если такого плейлиста на канале ещё нет, он создаётся (публичный) при первой загрузке; дальше находится по названию, регистр не важен.
- Работает везде, где идёт загрузка: форма Publish, загрузка из очереди рендера и недельное расписание (запланированное видео добавляется в плейлист сразу, а зрители увидят его там, когда оно выйдет).
- В форме Publish новая строка Playlist с галочкой «Add to the playlist “…”»; если её снять, выбор запомнится.
- В профиле стримера (Library → Streamers) поле «YouTube playlist» для своего названия (пусто = имя стримера) и галочка, чтобы клипы этого стримера в плейлист не добавлять.
- Если добавить не удалось (нет разрешения, кончилась квота), видео всё равно остаётся загруженным, а форма пишет почему. Аккаунтам, подключённым до 0.8.8, нужно один раз переподключиться в Accounts….
- Квота: +51 единица на загрузку (поиск плейлиста 1 + добавление 50), +50 один раз на создание плейлиста. Загрузка сама стоит 1600.
